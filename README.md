# Challenge México Vue + DRF

Sistema de simulación de arbitraje BTC en tiempo real usando Django REST Framework, Vue 3, PostgreSQL Neon, AWS Amplify y EC2.

## Stack

- Vue 3 + TypeScript
- Django REST Framework
- PostgreSQL / SQLite para pruebas
- AWS Amplify para frontend
- EC2 para backend
